Label differences
  BER VILL = BERLIN HEIGHTS VILLAGE
  KI VILL = KELLEYS ISLAND VILLAGE
  BV VILL = BAY VIEW VILLAGE
  CAST VILL = CASTALIA VILLAGE
  MIL VILL = MILAN VILL

  Township abbreviations expand as follows: BER = BERLIN,
  FLO = FLORENCE, GRO = GROTON, HUR = HURON, MAR = MARGARETTA,
  MIL = MILAN, OX = OXFORD, PER = PERKINS, VER = VERMILION.
  VER also expands to VERMILION for the five city ward precincts.

The graph crosswalk uses the precinct labels. Boundary continuity was
not assessed. Each precinct retains its own vote row.
